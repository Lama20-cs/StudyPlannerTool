# Study Planner Tool

A university group project for a Software Engineering course. We analyzed and designed a simple, offline study planner that helps students track tasks and deadlines in one place, with a **Focus Mode** that shows one task at a time.

## Problem

Students who take several courses at once often forget assignments, exams, and project deadlines, and find it hard to focus on one task while worrying about the others. Existing tools are usually too complex, so this project aims for something simple and beginner-friendly.

## Planned Features

- **Task management:** add, edit, and delete tasks (Assignment, Exam, Project, Lab, Reading) with deadline, priority, estimated time, and notes
- **Deadline extension:** quick options (+1 Day, +3 Days, +1 Week, or custom) with an optional reason
- **Focus Mode:** hides everything except the highest-priority task, with a countdown and "Mark Complete" / "Extend Deadline" actions
- **Task status:** Not Started, In Progress, Completed
- **Sort and filter:** by deadline, priority, type, and status
- **Alerts:** overdue and due-soon notifications, with color highlights plus text labels for accessibility
- **Progress and stats:** weekly bar chart, donut chart (completed / pending / overdue), and motivational messages
- **Offline use:** data stored locally
